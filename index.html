Six differences that don't map 1:1
01Resource groups are mandatory
Every Azure resource sits in exactly one. They scope RBAC, policy, deletion and cost rollups.
02Identity sits above billing
One Entra tenant serves every subscription. On AWS, IAM lives inside each account.
03Subnets span zones
Pick the zone per VM, disk or IP, not per subnet. "One subnet per AZ" is not an Azure pattern.
04NSGs can deny
NSG rules have priorities and explicit deny. Security groups are allow-only.
05Service ≠ Private Endpoint
A service endpoint only changes routing, like an S3 gateway endpoint. A Private Endpoint puts a private IP in your VNet, like PrivateLink.
06Zones aren't everywhere
Not every Azure region has availability zones, and zone redundancy is often opt-in per service.
